# 주식 시세와 예측 규칙

검증일: 2026-09-28 · 기준 커밋: `b7b1b69` · 근거: [S4](sources.md#s4), [S5](sources.md#s5).

## 현재가와 등락률을 분리해서 확인

미국 토스 시세는 실제 체결 시각을 공식 거래 달력의 구간과 비교합니다. 정규장 시작일이 거래일의 기준이며, 단순히 컴퓨터 날짜나 배열의 다음 일봉을 전일 종가로 사용하면 안 됩니다.

| 체결 세션 | 앱이 사용하는 등락률 기준 종가 |
| --- | --- |
| 주간·프리마켓·정규장 | 해당 거래일보다 앞선 가장 최근 정규장 종가 |
| 애프터마켓 | 해당 거래일의 완료된 정규장 종가 |

애프터마켓에는 정규장 종료 전에 요청한 일봉 캐시를 사용하지 않습니다. 세션이 모호하거나 체결 시각·기준 종가가 없으면 등락률은 비워 둡니다. 이미 시각이 있는 시세를 더 오래된 응답이나 시각 없는 응답으로 덮어쓰지 않으며 미래 체결도 거부합니다. 따라서 현재가가 같아도 기준 종가가 다르면 등락률이 달라집니다. 근거는 `StockQuoteCodec.accepts/usSession/changeBasis`와 Windows `quoteContext/canAcceptQuote`입니다. [S4](sources.md#s4)

## 차트와 조회

- 표시할 봉은 최대 20개입니다. 이동평균·분석에 필요한 과거 봉은 표시 범위보다 많이 읽을 수 있습니다.
- 차트 갱신 간격은 종목·봉 종류별로 1분봉 60초, 10분봉 600초, 일봉 86,400초입니다. 10분봉은 1분봉을 묶어 만듭니다. 시세와 등락률 기준 종가의 갱신은 이 차트 주기와 별개입니다.
- Finnhub 모드는 미국 시세용이며 토스 차트·분석이 지원된다고 표시하지 않습니다. [S2](sources.md#s2) · [S4](sources.md#s4)

## 예측이 실제로 하는 일

현재 GBM은 기대수익률을 0으로 둡니다. 예상 종가의 기댓값은 입력 현재가이고, 관측한 변동성과 정규장 마감까지 남은 시간으로 상승 확률과 가격 구간을 구합니다. 선택한 봉이 바뀌면 변동성 입력이 달라지며 목표는 같은 날 정규장 종가입니다. 이는 검증된 적중률이나 매매 수익률이 아닙니다. [S5](sources.md#s5)

관심 종목 예측은 보유 종목 없이 사용할 수 있고, 계좌 선택은 별도 동의입니다. 저장한 예측과 관측 추이는 구분하며 놓친 과거 예측을 사후 생성하지 않습니다. [S2](sources.md#s2) · [S4](sources.md#s4)

macOS의 수동 Codex 분석은 공개 체결가·정규장 시각·완료 일봉을 고정한 입력을 사용합니다. 현재 프롬프트는 뉴스·외부 시세·파일·계좌 자료를 사용하지 않도록 제한하며, 실제 모델명과 결과를 보관하고 같은 입력의 GBM과 비교합니다. 이 위키를 만들었다고 Codex 입력에 위키나 뉴스가 추가되는 것은 아닙니다. [S5](sources.md#s5)

## 수정 전에 점검할 것

1. 현재가, 체결 시각, 세션, 거래일, 기준 종가 날짜를 각각 비교합니다.
2. 과거·미래·시각 없는 응답, 휴장일, 정규장 종료 경계와 캐시를 회귀 검사합니다.
3. 모델을 비교할 때 같은 종목·시점·입력·평가 대상을 사용합니다. 이미 결과를 본 기간을 새 평가로 포장하지 않습니다.
4. 계좌번호·수량·잔고·인증 정보는 위키와 공개 이력에 넣지 않습니다.

프로젝트 범위는 [목표](project.md), 배포와 플랫폼 검증의 한계는 [검증 페이지](maintenance.md)에서 확인합니다.
