# PenguinNotch 개발 지식 위키

검증일: 2026-09-29 · 초기 코드 기준: `b7b1b69d29944f76f7431933d5d78a41c135f81f` · 현재 정식 배포: [v1.22.0](https://github.com/pmh10401/PenguinNotch/releases/tag/v1.22.0), [S12](sources.md#s12)

후속 변경: [Windows 설정 분류](project.md#windows-설정-분류)는 1.20.5에서 추가됐으며, [1.21.0 원본 통합](maintenance.md#원본-업데이트-통합)은 CodeNotch 1.19.0을 병합한 소스 기준입니다. 공개 릴리즈와 실제 Windows 기기 검증은 별도입니다.

1.21.1에서는 [빠른 드래그의 놓기 처리](maintenance.md#빠른-드래그의-놓기-처리)를 보완합니다. 원본 통합의 로컬 성공과 GitHub CI 실패는 [S10](sources.md#s10)에 구분해 기록합니다.

1.21.2는 [합성 이벤트의 좌표 문제](maintenance.md#합성-이벤트의-좌표-문제)를 확인한 뒤 테스트 입력만 분리한 후속 소스입니다. 최종 코드 `3fe7ab5`의 macOS·Windows CI가 통과했습니다. [S11](sources.md#s11)

정식 릴리즈 1.22.0의 [공통 조작과 남은 플랫폼 차이](project.md#1220-공통-조작과-남은-차이)를 별도로 관리합니다. 같은 기능의 설정·계산 규칙과 운영체제별 제한을 구분합니다.

Karpathy의 [LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)를 PenguinNotch에 적용한 개발 지식 모음입니다. 원자료, 근거를 연결한 요약, 유지 규칙을 분리하고 새로 확인한 내용을 누적합니다. 기존 코드와 문서는 Git 커밋으로 고정하여 원자료로 사용합니다. [출처 목록](sources.md)은 그 시점의 기록이며, 현재 동작을 변경하기 전에는 최신 코드를 다시 확인해야 합니다.

## 사용 예

- “주식 시세와 예측 규칙을 읽고, SOXL의 현재가가 같아도 등락률이 달라지는 조건을 출처와 함께 설명해줘.”
- “이번 노치 수정에서 확인한 내용만 관련 위키와 변경 이력에 반영해줘.”
- “위키를 점검하고 코드와 다른 설명, 끊어진 링크, 검증되지 않은 주장을 알려줘.”

저장소 루트에서 검색할 수 있습니다.

```sh
rg -n '등락률|세션|스크롤|키체인' docs/wiki
rg '^## \[' docs/wiki/log.md
```

## 현재 범위

앱 개발에 필요한 공개 지식만 담습니다. 실시간 시세·뉴스 수집, 계좌 자료 저장, 위키를 읽는 예측 기능은 연결하지 않았습니다. 뉴스나 기업 분석용 위키를 추가한다면 문서의 발표 시각과 조회 시각을 구분하고, 당시 알 수 없었던 자료가 과거 예측 평가에 들어가지 않도록 별도 설계해야 합니다.
