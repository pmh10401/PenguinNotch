# 노치와 릴리즈 검증

검증일: 2026-09-28 · 코드 기준: `b7b1b69` · 배포 기준: `v1.20.4`의 `e8cea61`.

## 노치 스크롤의 유지 조건

화면보다 긴 목록만 휠·트랙패드로 이동합니다. 네 방향과 원형·막대를 지원하며, 상하 노치에서도 세로 휠을 사용할 수 있습니다. 목록이 들어맞으면 스크롤하지 않습니다. 노치 본체·손잡이는 화면 안에 유지하고 호버 카드의 스크롤은 따로 처리합니다. [S3](sources.md#s3)

렌더링과 호버·클릭·드래그의 좌표가 같은 스크롤 위치를 사용해야 합니다. 보이지 않는 항목은 입력 대상에서 제외하고, 항목 수가 줄면 이동 범위를 다시 제한합니다. 짧은 클릭과 Option/Alt로 노치를 옮기는 동작도 보존합니다. macOS `NotchScrollTests`와 Windows 브라우저 검사는 이 조건을 확인하는 출발점입니다. [S3](sources.md#s3)

## 원본 업데이트 통합

2026-09-29 KST에 CodeNotch 1.19.0을 PenguinNotch 1.21.0(macOS build 58, Windows r50) 소스에 반영했습니다. 기존 스크롤은 카메라 옆 배치에서도 같은 렌더링·입력 좌표를 사용합니다. 긴 목록의 보이는 길이와 손잡이는 화면에 맞추고, 투명한 애니메이션 여유 공간 때문에 카메라 기준점이 이동하지 않도록 처리합니다. 주식의 단일 항목은 가격·등락률 교대와 방향 색상을 유지합니다. [S9](sources.md#s9)

macOS의 새 업데이트 카드는 사용자가 **업데이트** 또는 **나중에**를 선택합니다. 주식 저장·모델 계산 방식은 유지하며 연구 스크립트·평가 결과를 앱에 채택하지 않습니다. 검증 범위는 S9에 기록합니다. 이 병합 자체는 정식 설치 파일 배포·설치가 아닙니다.

최종 로컬 검증은 macOS 전체 2,186개 중 실패 0·건너뜀 11개, Windows Rust 184개 통과·4개 제외, Windows GNU 교차 컴파일, Node 19개 및 브라우저 설정 24개·노치 48개 배치 검사입니다. 노치를 옮기거나 늘릴 때도 스크롤 위치와 표시 형식, 화면에 보이는 항목만 유지합니다. Apify의 명시적인 키체인 접근 허용, Codex 완료 알림, JSON 합계 범위 검사도 포함합니다. 실제 Windows 창 동작과 실제 계정은 별도 검증 대상입니다. [S9](sources.md#s9)
